配布形態
9/20 に App Store で一般公開 9/20 は PWA — QRからホーム画面に追加

成田様の法人化がこれからで D-U-N-S 番号を取得できず、ストアの法人アカウントが作れないため。PWA なら審査もアカウントも不要で、9/20 に間に合います。

アカウント名義
すべて開発者の1アカウント ストアのみ成田様の法人名義

ストアには「販売元」として名義が表示され、規約上の責任もかかります。インフラ(Supabase / Vercel / GitHub / Resend)は開発者名義のままで問題ありません。

スコープ
削る候補を検討中 会員側・管理者側とも 9/20 対象で確定

お客様に触っていただくため両方必要、との判断。Step 4(予約)と Step 5(管理者機能)がともに必須になり、日程の余裕がなくなりました。

022つのトラックに分かれます

9/20 のデモと、その先のストア展開は、必要なものがまったく違います。 下の2本は独立して進むので、ストア側の待ち時間がデモを止めることはありません。

05今日着手いただく3つ

3つとも GitHub でサインインするので、続けてやると 60〜90分で終わります。

  1. GitHub アカウントとリポジトリ

    2FA を有効化してリカバリーコードを保管。リポジトリ fitgym-app を Private・空(READMEのチェックは外す)で作成。

  2. Vercel アカウント

    「Continue with GitHub」でサインインし、リポジトリアクセスを承認。これで HTTPS のURLが発行され、QR配布が可能になります。

  3. Supabase プロジェクト

    Region は必ず Northeast Asia (Tokyo)。ここを間違えると作り直しです。作成後、Project URL と anon キーをお知らせください。

今週中に、独自ドメインの取得と Resend の登録もお願いします。 QR配布自体は vercel.app のURLで可能ですが、独自ドメインが無いとパスワード再設定メールを実際に送れません。 DNS の反映に最大48時間かかるため、早いほど安全です。
